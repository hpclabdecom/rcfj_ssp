# `instances/scaled10/`

`lcbrtu_3`, `lcbrtu_5` and `lcbrtu_8` of the benchmark with every processing time multiplied by 10 and everything
else unchanged (`experimentos/gera_instancias.py --escala10`). They serve one sensitivity arm of the pre-registered
pre-registered campaign (`experimentos/PREREGISTRATION.md`, block C): PT-W and TW-LNS are run on them with the unscaled
Table 10 budgets to measure how the thermal controls, which are expressed in makespan units, depend on the time
scale of the instance. Check with `sha256sum -c SHA256SUMS`.
